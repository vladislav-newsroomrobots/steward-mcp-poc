Block A

Sign-in & access

Same trust model as the extension: users sign in on the Steward platform, exchange a 60-second code for a 7-day session. Admins can skip the dialog entirely with environment variables.

A1First sign-in

A new user asks for a letter before connecting. Claude walks them through the one-time exchange.

User
Write a renewal letter for the Knight Foundation
Claude
Let's connect your Steward account first. Open tools.theajp.org, sign in, and copy your connection code — it's valid for 60 seconds.
User
Code: eyJhbGciOiJIUzI1NiIs…
Claude
✓ steward_exchange_auth_code
Signed in: maria@riversidechronicle.org · Riverside Chronicle · role journalist · session valid 7 days
Connected. Now, about that letter — pulling your Knight Foundation context…

Under the hood: the code comes from the platform's session-code endpoint under the user's Clerk session; the 7-day token is cached locally, so this happens at most once a week.

A2Session expired

User
Generate a funder update
Claude
✕ steward_generate_draft · 401
Your Steward session has expired (7-day lifetime). Grab a fresh code from the platform and I'll pick up right where we left off — your context is preserved.

A3Access revoked mid-work

If an org admin removes a user, the backend rejects the next call with a specific code. Claude explains instead of retrying blindly.

Claude
✕ steward_generate_draft · 403 organization_access_denied
Your access to Riverside Chronicle's Steward workspace has been revoked. Please contact your organization admin — I won't retry until access is restored.

Handled codes: extension_access_revoked, insufficient_role, organization_access_denied, user_already_in_another_organization.

A4Zero-dialog setup for teams

# One-time admin setup — no sign-in dialog for end users $ export STEWARD_ACCESS_TOKEN=… STEWARD_ORG_ID=org_2ab… STEWARD_API_BASE_URL=https://tools.theajp.org/api $ claude mcp add steward -- node /opt/steward-mcp/dist/index.js

Block C

Draft generation

The core of the product. Drafts arrive in Steward's canonical rich-text format and render in a draft viewer with versioning, editing, copy, and feedback — the full extension experience, inline in chat.

C0Zero-context request — Steward suggests who it's forTry it

The user names only the document. Claude calls steward_suggest_context, which matches the request against the workspace and returns ranked suggestions: the best-fitting document type, funders scored by name mentions and grant history, renewal-stage opportunities, and the active draft to continue. The user picks with one tap instead of filling out a form.

Under the hood: ranking is transparent and cheap — name overlap with the request, last-grant amount from funder records, opportunity stage fit (renewal-flavoured requests boost renewal-stage deals), plus the active session from steward_get_workspace. Claude is instructed to call this tool automatically whenever a generation request arrives without context objects.

Block E

Versions & feedback

Every generation, manual edit, piece of feedback, and copy event is versioned server-side — a complete audit trail per session. The live controls are in the C1 draft viewer above; here's what each does.

E1Manual edit → new version

User
I rewrote the second paragraph myself — save it as a new version
Claude
✓ steward_save_user_edit · editedFrom 2
Saved as version 3 · marked "your edit" in the timeline

E2–E3Tagged feedback

The product requires one tag per rating — the same eight tags as the extension. Positive: Strong funder alignment · Clear impact + metrics · Used my context well · Well framed for this audience. Negative: Too generic · Weak alignment · Missing impact or metrics · Tone didn't fit.

Claude
✓ steward_submit_feedback · like · "Used my context well"
Thanks! Your feedback helps Steward learn your funders.
Noted. Want me to lean into that context even more on the next draft?

E5Copy, Gmail-ready

One click writes both clipboard flavours — rich HTML (blockquotes and lists survive pasting into Gmail) and clean plain text — and records the copy event for analytics.

⧉ Copy→ text/html + text/plain→ steward_track_copy

Block H

Errors & limits — the user's view

Every failure mode maps to a plain-language response. No raw stack traces, no silent retries.

H1Duplicate feedback (409)

User
Like this version again
Claude
✕ steward_submit_feedback · 409 feedback_already_given
Version 2 already has feedback. I can retract it, or you can rate a different version.
